Your Align calendar widget

Use Scriptable on your iPhone. No Mac or developer membership needed.

  1. Tap Copy widget script below.
  2. Open Scriptable, tap +, paste the script and name it Align.
  3. Tap the play button. Choose Sign in / update events. Enter your Align email and password in the prompt, then tap Sign in and save events. Version 1.4 does not open a browser window.
  4. Hold an empty area on your Home Screen → Edit → Add Widget → Scriptable. Choose medium size.
  5. Hold the new widget → Edit Widget → Script → Align. Set Parameter to next, today, 3days or week. Use a large widget for several days.

Run the script and choose Display settings to choose the default view, maximum events (1–7), location and end time. Settings apply to all widgets; each widget’s Parameter overrides its view. Small shows one event, medium up to two, and large up to six. Extra events are counted as “more”. Today includes completed shifts; three days and week start today.

The widget shows saved Align and imported-calendar events. Run the script to update it after calendar changes. Tapping the widget opens Align. iOS controls when widgets redraw.

The script stores selected event details locally in Scriptable, not your password. Clear them using “Clear saved events” in the script. Signing out in Safari does not clear this separate snapshot. Initial iPhone testing is still needed.
